# llm-soft-hard-news-validation
Replication materials for a thesis on LLM-based soft–hard news classification and psychometric validation.

## How to run
Run scripts in ascending numerical order (01_, 02_, 03_) within each folder.

Recommended pipeline:
1) scripts/Method1/
2) scripts/Method2/
3) scripts/Method3/
4) scripts/Finalanalysis/

## Results
Aggregated outputs are stored in `results/`, mirroring the script structure.
